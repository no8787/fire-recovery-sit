## 2. 지금 어디까지 하다가 멈췄는지

`docs/Sprint3_2단계_지시서.md`(Downloads에 있던 원본, 2단계 상세 지시서)의
섹션 3 "이번 단계에서 구성할 섹션" 6개 중 **1번(Hero)만 완료**, 나머지는 미착수:

  1. Hero                    ← ✅ 완료 (이미지만 교체)
  2. 신뢰 지표               ← ❌ 미착수 (StatsSection.tsx 손 안 댐)
  3. 화재 피해 고객의 문제   ← ❌ 미착수 (신규 컴포넌트, 아직 없음)
  4. 화재복구 프로세스 5단계 ← ❌ 미착수 (기존 7단계 ProcessTimeline 그대로)
  5. 전문 솔루션 4종         ← ❌ 미착수
  6. 전문성 / 실제 사례 연결 ← ❌ 미착수

**사용자가 이미 지정한 체크포인트**: "화재복구 프로세스 5단계 섹션을 만든
직후에 한 번 멈춰라. 솔루션 카드로 넘어가기 전에 이미지 배치를 확인하겠다."
→ 즉 4번까지 만들고 나면 STOP, dev 서버 3000 포트로 띄우고 데스크톱 1440 +
모바일 390 스크린샷 찍어서 보고 후 승인 기다려야 함. 아직 2번도 시작 못한
상태라 이 체크포인트에는 한참 못 미침.
